### About

Domainwarden is a little project I have been working on. Built with Laravel, React and Inertia, it aims to make domain monitoring easy.

With Domainwarden, you can monitor your WHOIS/RDAP, DNS and SSL status and receive notifications via many preferred options when something goes wrong.

Domainwarden was born out of a desire as I have a lot of domains and I wanted to keep an eye on them, the offerings available weren't great, often a poor UI or ridiculous paywalls so I built my own.

The docs are pretty extensive, with a nice API (I think so!) included as well. Highly recommend reading!

If you're interested, please [check it out](https://domainwarden.app).
